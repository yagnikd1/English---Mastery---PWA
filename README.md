# English Mastery PWA

Public GitHub Pages deployment of the original English-learning PWA.

## Included
- 30-day personalized course
- Auto-save and exact resume
- Quizzes, writing tasks, speaking prompts, recordings, backup/recovery
- Offline app shell and Android readiness tools

## Not included
Third-party books, PDFs, answer keys, or audio files are intentionally excluded from this public repository. The lesson references are designed to be used with the learner’s own lawful local copies.

## GitHub Pages
After upload, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
